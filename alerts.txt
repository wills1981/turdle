# Turdle notices: a pop-up shown when the game opens. Closing it hides it until the next visit (browser session).
#
# Each notice is   KEY: "<html>";   where KEY is
#   a UK date, YYYY-MM-DD  -> shown on that day only
#   a weekday, e.g. FRIDAY -> shown every week on that day (comment it out to stop)
# A dated notice wins over a weekday one on the same day.
# The HTML ends at the first line ending in  ";  so attributes like width="50" are fine inside.
# Images: give just the filename; it's loaded from images/ (subfolders too: src="xmas/tree.png" -> images/xmas/tree.png).
# Lines starting with # are ignored, so commenting out a notice's first line switches it off.
#
# Examples (switched off):
#2026-12-25: "
#<h2>Heading</h2>
#<p>Text</p>
#<img src="image.png" width="50">
#";

2026-11-17: "
<center style="font-size:50px;line-height:1;">💩</center>
<h2>Happy Tuesday Turdlers!! </h2>
<p>Due to popular demand and feedback from players Paul and Shelley, <strong>3-letter</strong> puzzles have now been ditched in favour of <strong>4-6 letter</strong> puzzles. General difficulty is going to be increased from tomorrow onwards without making the puzzles too tricky!</p>
<p>Have fun and <strong>HAPPY TURDLING!!!</strong></p>

";
